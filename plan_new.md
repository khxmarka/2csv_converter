# Plan: конвертация `.xlsx` / `.xls` в CSV

План для исполнителя-ИИ. Норматив: актуальный `CONSTRAINTS_AND_POLICY.md` (Excel — §13; формат ячейки — §6; обход — §3; лог — §8). Старый `EXECUTION_PLAN.md` удалён: первоначальная сборка SQL-конвертера уже сделана.

**Этот документ — только новая фича Excel.** Конвертер SQL уже существует и работает: не переписывать CLI, корень `C:\Source\db`, парсер INSERT, склейку таблиц, `csvout` (формат кавычек) и `converted.txt` с нуля. Расширять: обход (ещё `.xlsx` и `.xls`), запись CSV листов, учёт успеха Excel в `converted.txt`, лог папки по всем рабочим файлам.

Работа **только по пунктам**. К следующему не переходить без явного апрува («ок», «апрув», «пункт N принят»). После каждого пункта: что сделано, стоп-критерий, ждать.

Язык: **Go**. Если план и политика расходятся — остановиться и спросить, не импровизировать.

---

## Зачем

Нужно, чтобы тот же `sql2csv` кроме SQL обрабатывал книги Excel (`.xlsx` и `.xls`): каждая ячейка в двойных кавычках, разделитель запятая, каждый лист — отдельный CSV рядом с исходным файлом. Если в книге **больше 5 листов** — файл целиком не трогать.

## Пункт 1. Чтение `.xlsx` / `.xls`: счётчик листов и строки

**Сделать:**

- пакет (например `internal/xlsconv`) на минимальных зависимостях чтения Excel (xlsx и xls — отдельные библиотеки, свой разбор ZIP/XML и BIFF запрещён);
- функция: открыть книгу, число листов; если `> 5` — вернуть «пропуск всей книги», без строк;

- юнит-тесты на фикстурах **в репозитории** (не в `C:\Source\db`), для **обоих** форматов: 1 лист; 2 листа; 6 листов → skip; пустой лист; кавычка внутри ячейки как данные (ещё не файл CSV).

**Не делать:** запись CSV на диск, обход `C:\Source\db`, правки CLI/`converted.txt`/парсера SQL.

**Проверка:** `go test` пакета; книга с 6 листами не отдаёт данные листов.

## Пункт 2. Запись CSV листов рядом с Excel

**Сделать:**

- для каждого непустого листа: CSV в директории книги, формат §6 (всегда `"..."`, запятая, UTF-8 без BOM, LF, `"` → `""`);
- **заголовок** = первая строка листа (шапка таблицы); остальные строки — данные; INSERT в Excel не разбирается;
- ширина = max колонок среди записанных строк, короткие дополнять `""`;
- имя `{книга}_{лист}.csv` / `{книга}_{лист}(n).csv` при занятом имени; санитайз как у таблиц;
- каждый лист через временный файл; провал листа 2 не удаляет CSV листа 1;
- не дописывать лист в CSV от SQL-INSERT.

**Не делать:** менять парсер SQL, склейку INSERT, корень, `--help`.

**Проверка:** юнит-тесты (фикстуры в репозитории), для `.xlsx` и `.xls`:

1. один лист → один `{book}_{sheet}.csv`, первая строка — заголовок, все ячейки в кавычках, разделитель запятая;
2. два листа → два CSV, не один скленный файл;
3. шесть листов → ни одного CSV;
4. заранее лежащий одноимённый CSV не затёрт, новый файл с `(n)`;
5. в ячейке есть `"` → в CSV `""`;
6. пустой лист не создаёт файл, соседний непустой — создаёт.

**Стоп:** ждать апрув пункта 2.
